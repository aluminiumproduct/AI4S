# 合成预审与 XRD 演示

## 启动

```bash
npm ci
npm run setup:synthesis
PORT=3001 npm run dev
```

需要 Node.js 20.19+ 或 22.12+、Python 3.12。科学依赖安装在被 Git 忽略的 `.venv/`；也可通过 `AI4S_PYTHON` 指定已有 Python 环境。原有材料和聊天配置不变。

## 路演路径

1. 点击页头“合成预审 · XRD”，或候选卡片、推荐表中的“合成 / XRD”。
2. 点击“一键路演”：载入 SrTiO₃ 晶胞、默认工艺与高纯相演示谱，展示约 98.4% 的主相拟合贡献。
3. 点击“载入含杂相演示”：展示约 65% 的主相贡献、TiO₂ 杂相及预警。
4. 修改温度、气氛、射线、角度范围或峰宽，观察预审或模拟谱变化。谱线悬停可查看 hkl 与晶面间距。
5. 拖入两列 2θ/强度的 `.xy`、`.csv`、`.txt` 或 `.dat` 文件，自动对齐与比对。可下载谱图和 JSON 实验报告。
6. 点击“反馈主动学习”，关闭实验室；候选的合成先验和获取分数随即更新，后续采样使用新排序。

在 Mock 数据中 SrTiO₃ 已有关联候选，可直接完成整条流程。独立导入结构可先选择关联候选，再提交反馈。样例明确标为演示实验谱；上传文件按实验文件记录。实验记录和谱图保存在当前浏览器的 IndexedDB，反馈摘要保存在 localStorage。

## 实现口径

- XRD 使用真实 `pymatgen.XRDCalculator`，输入原始晶胞与占位，不使用显示超胞。连续谱采用 Gaussian/Lorentz 混合峰形。
- 比对使用非负最小二乘拟合主相和内置参考相，搜索 ±0.25° 零点偏移；显示主相拟合贡献、主相指纹一致性、峰覆盖及未解释峰。
- 预审优先使用 MP 对应材料的能量高于凸包值；无数据库数据时使用可重复的演示估算，并显示来源。当前模块接收已有结构，不执行 uMLIP 弛豫或高温自由能计算。
- 主相百分比是当前参考谱模型的拟合贡献；当前演示不提供经过标定的绝对质量纯度。
- 反馈作为独立的合成先验约束影响获取分数，不改写带隙或 Mock 目标。正分数乘以先验，负分数除以先验，避免高风险材料因负号反而获得优先级。重复反馈替换原记录，不重复惩罚。

## 验证

`npm test` 包含两列谱图解析、重复反馈、负分数约束、下一轮真实采样选择，以及安装 Python 环境后运行的 SrTiO₃ 峰位、98.4%/65% 已知混合谱恢复与零点偏移测试。原有模型、结构、顾问和网络回归测试保留。
