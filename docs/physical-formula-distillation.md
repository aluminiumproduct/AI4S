# 白盒物理公式蒸馏引擎

该模块在现有主动学习旁路生成候选解析模型，保留原教师模型、获取函数及不确定性处理。默认20条采样记录、至少8个独立组成后自动触发；新增10条或停止采样后可自动更新，也支持手动搜索、停止、目标切换和JSON导出。8组是运行护栏，不是泛化可靠性的保证。

## 数据与目标

- 使用原始单位的五类组成属性均值、总体方差和极差；不把22维模型特征中的零占位当作物理测量。覆盖率不足的属性保留null，发现集中缺失或恒定的列排除。coverage、validity和已有Goldschmidt容忍因子不进入表达式搜索。
- 使用当前 Data Hub 的实际目标、单位与方向，支持七种目标；保留的 Mock 接口为合成评分/a.u.。来源、保真度、条件组、版本和引用逐记录进入快照/导出，不将实验值统一称作 MP 带隙。同组成副本不增加独立组成数。
- 按归一化组成分组，忽略化学式整体倍数和元素顺序。一个组成的所有记录在同一分区；符号拟合及各模型测试误差按组成等权，防止副本数量主导结果。教师和Ridge仍沿用现有回归器的训练约定。
- 快照只把已采样记录的标签送入公式Worker，候选查询只含特征与元数据。地图默认仅按已采样值着色；预测高亮需单独开启。

## 符号搜索

1. 首次按种子和组成键确定约60%/20%/20%的发现/选择/测试分组，后两区各至少2组。本轮内冻结已有组成归属，新增组成按独立hash桶分配，避免连续自动更新时训练/测试组互换。重置/换数据后建立新分组；划分及样本数写入结果。主动采样池上的评估仍是回顾性评估。
2. 只用发现集选择最多8个基础输入，按相关性进行有界算符组合。支持加、减、乘、除、绝对值、指数和平方根。默认深度3、最多9节点、6000次数值候选评估；设置允许最多深度5、15节点、12000次。
3. 表达式保留能量与长度量纲；加减要求同量纲，指数要求无量纲，平方根改变量纲。负数开方、接近零的分母、指数参数绝对值超过12、非有限结果及大于1e12的值均视为无定义，不静默裁剪。除法保护阈值根据发现/伪目标训练数据尺度固定，并写入AST。
4. SIS相关性预筛到64个候选；真实L1坐标下降使用训练集中心和尺度。保留最多12项，枚举单项/双项组合，按选择组误差及L0项数/复杂度惩罚选择模型。L1全部收缩为零时记录0项，并回退到SIS候选。
5. 选定表达式后，用发现与选择数据重拟合系数，再一次性计算测试误差。测试无定义记录计数报告，不依据测试结果改选公式。

输出为 ŷ = b0 + b1 Φ1 + b2 Φ2（允许单项），显示原始单位表达式、系数及系数单位。内部标准化仅用于筛选。均值、Ridge、教师和解析模型统一在公式可计算的同一测试子集比较，并显示有效记录/组成数及域外计数。单描述符模型的地图可用有明确标记的辅助轴，辅助轴不参与预测。

## 教师蒸馏

教师模式使用所选模型类型及参数，在发现组上重新训练隔离教师。它与使用全部已采样点的在线教师不是同一个训练快照；界面报告实际教师训练数。

伪目标查询最多600条，不含选择/测试组成，不读取未采样标签。表达式以冻结教师均值拟合，选择组也只使用同一教师预测。最终测试同时报告教师忠实度与真实标签误差。伪目标数量不代表新增真实材料标签；教师输入已含已知物理先验，因此公式回收不自动代表独立物理发现。

这些测试组未参加本次符号搜索或隔离教师训练；在线主动学习仍使用全部已采样标签进行原有采样决策。因此这属于主动选中样本池内的回顾性检验，不能直接替代前瞻性的发现性能实验。

## 补充键能和几何

“搜索参数与补充物理数据”支持按材料ID输入JSON，每个物理量必须含有限value、固定unit、source和reference：

~~~json
{
  "mp-material-id": {
    "bond_energy_mo": {
      "value": 4.1,
      "unit": "eV",
      "source": "实际数据或计算来源",
      "reference": "键解离反应、参考态与适用环境"
    }
  }
}
~~~

上例只说明格式，不是内置测量数据。可用键及单位：

| 键 | 单位 | 需要的定义 |
| --- | --- | --- |
| bond_energy_mo | eV | M–O解离反应、环境和参考态；须为正 |
| octahedral_distortion | 1 | 无量纲畸变算法与配位选择；须非负 |
| volume_change_per_atom | Å³/atom | 同一参考结构/化学式的每原子体积差 |
| chi_A / chi_B | 1 | 明确的A/B位点、组成与电负性约定 |

数据可来自uMLIP、DFT或可信文献的后处理，模块本身不运行uMLIP，不从组成猜测结构，不把原子化学硬度代作键解离能。不完整的补充列不会被零填充参加搜索。

## 界面与生命周期

- “切换公式坐标”显示解析表达式轴、快照及域外/缺值候选数；最多投影1800点。金色区域按目标方向选择优选点（最大化取高值，最小化取低值），少于三个非共线点不绘制凸包。预测与观测高亮明确区分。
- 原子特征坐标仍可切回，候选真实标签不会显示在hover中。
- 独立Worker支持取消、40秒超时和重启。加载、重置、模型/参数/补充数据改变及卸载会取消旧计算；请求序号和快照ID阻止旧回复覆盖新状态。
- 正常主动学习继续时可显示上一快照的公式，保留轮次和训练数。它不会自动替换在线教师或改变EI/UCB。
- JSON包含AST、保护阈值、单位、系数、数据目标、完整教师参数、特征索引字典、特征/元素表版本、实际搜索参数、划分、误差和完整净化输入快照。数据校验摘要覆盖候选查询及补充数值；未采样真实标签仍不会进入快照或导出。

## 验证与启动

npm test 覆盖量纲/定义域、L1独立解析参考、OLS、组隔离、隐藏标签边界、保留标签投毒、教师标签隔离、确定性与Worker取消/过期回复/超时。

/tests/browser/distillation.html 使用真实Worker检查已知合成关系、教师模式与取消重启。合成关系回收验证数值与接口，不证明真实材料规律。

    PORT=4311 DISABLE_HMR=true npm run dev

默认3000端口的其他工作树可以继续运行。
