# 代理模型实现与验证

## 可用模型

| 模型 | 预测实现 | σ 的来源 | 主要参数 |
|---|---|---|---|
| RBF GPR（默认） | 精确 GP，Cholesky 求解，不求显式逆 | 潜在函数后验标准差，不含观测噪声 | 长度尺度倍率、噪声 σ |
| Random Forest | Bootstrap CART；每个节点随机抽取可分裂特征，搜索平方误差最小阈值 | 树间预测的样本标准差 | 树数、深度 |
| Extra Trees | 完整训练集，每节点随机特征及一个随机阈值，无 Bootstrap 行抽样 | 树间预测的样本标准差 | 树数、深度 |
| GBDT | 平方损失的残差提升；8 个 Bootstrap 提升器，单树深度最多 3 | 完整提升器之间的样本标准差 | 副本数、提升轮数、学习率、深度 |
| kNN | 标准化空间的欧氏距离，反距离加权；精确重合点取均值 | Bootstrap 近邻模型分歧 | k、副本数 |
| Ridge | 带不惩罚截距的 L2 正则线性回归，Cholesky 求解 | Bootstrap 岭模型分歧 | λ、副本数 |
| Linear SGD | 5 个 Bootstrap 线性模型，100 轮、按维度与最大样本平方范数约束学习率 | 五个预测的样本标准差 | 种子 |

这是自包含的 TypeScript 回归实现，没有把不同算法标签映射到同一个线性模型。新增模型不需要 API Key、Python 服务或下载权重。保留的 SGD 对照经过训练集标准化和学习率稳定处理，不保证与旧版数值完全一致。树的最小叶样本数固定为 2，默认森林 48 棵、最大深度 6；常量列不进入节点的随机特征候选集。Extra Trees 的单个随机阈值无法满足叶约束时允许停止分裂。

## GP 数值约定

只根据已采样训练数据拟合每列均值、总体标准差以及目标均值和标准差。常量列和常量目标的尺度取 1。预测的均值和标准差转换回原目标单位。Bootstrap 共享当前完整训练集的标准化变换；不使用未采样目标或预测批次来拟合尺度。

标准化空间内，核为 `k(x,z)=exp(-||x-z||²/(2ℓ²))`，幅度固定 1。`ℓ` 是正训练点距离中位数乘以用户倍率；没有正距离时用 1 作为基准。无对数似然优化；用户设置的噪声默认 0.05（标准化目标单位），不是从观测中估计的噪声。

`LLᵀ = K + (noise² + 1e-10)I`；`α = L⁻ᵀL⁻¹y`；`μ=kᵀα`；`σ_f²=max(0,1-||L⁻¹k||²)`。输出潜在函数方差，不再加观测噪声；`1e-10` 只用于数值稳定。该方差随训练点的核相似性变化，几何空间取决于当前描述符和缩放，不等同于真实化学距离或保证校准的置信区间。

森林和 Bootstrap 的分歧标准差采用 `B-1` 分母，没有统一的 `+0.1` 或其它人为底座。分歧可以为零，尤其是小样本、重复样本或所有预测相同的情况；这不能证明预测正确，也不包含全部噪声、模型偏差或域外风险。森林树间分歧不是整个森林均值估计量的标准误。非 GP 的 EI/UCB 借用高斯形式作为启发式排序。

## 后台执行与数据边界

App 使用 `ModelWorkerClient`；数值核心 `SurrogateModel` 只在 Worker 中执行（Node 测试和基准直接调用核心）。每轮先训练，再一次性批量预测候选的边际均值/方差。预测消息只含 `features`，不发送未采样 `trueProperty`；训练消息仅含已采样特征与目标。取消终止 Worker 并拒绝未完成 Promise，下次任务重新创建 Worker。错误、反序列化失败及单任务超过 30 秒也会清理 Worker。

App 的加载、停止、重置和卸载同时取消任务、递增版本。旧结果及旧 finally 都不能提交到新版本。切换模型/参数需在无迭代的状态，避免在同一历史中混用模型。显示耗时是 Worker 内实际拟合/预测时间，不包含启动、消息拷贝、渲染，也不是材料计算时间。

固定种子控制模型抽样、初始材料采样、Mock 组成生成和 Random 获取分数；在相同数据、输入顺序、参数和运行环境下可复现。真实与 Mock 记录共用22维确定性组成特征：五类参考元素属性的均值、总体方差、极差和覆盖率，以及有条件的 ABO₃ 容忍因子及有效位。缺值保留覆盖率标记；这些特征不能区分同质异构体。AI 顾问快照携带实际特征 schema、缩放除数、缺值说明及所选模型和参数，按模型说明 σ 的含义。

## 规模与验证

精确 GP 的训练约 `O(n³+n²d)`、内存 `O(n²)`；预测 m 个边际方差约 `O(mn²+mnd)`，不构造 `m×m` 候选协方差。n 是已采样训练数，m 是候选数。硬上限：GP n≤256、其它 n≤1024、d≤128、m≤20000、树≤128、深度≤10、Bootstrap 副本≤16、提升轮≤100。遇到上限明确失败，不静默丢弃训练数据或降级模型。这些限制是工程护栏，不是所有设备上的速度承诺。

`npm test` 包含 GP 单点和两点的独立解析参考、远近方差、非线性留出点、单位变换、重复/常量/小样本、确定性、错误和资源边界、候选标签隔离、异步批量顺序与取消重启测试。`npm run benchmark:models` 输出固定种子合成任务的耗时及留出 RMSE；`/tests/browser/models.html` 验证真实浏览器 Worker 及动画心跳。性能受设备、浏览器、维度、参数影响。合成验证不代表真实材料泛化、σ 校准或主动学习发现速度。

后续科学验证应按组成/结构分组拆分材料，避免多晶型泄漏；再测试 MAE/RMSE、负对数似然或覆盖率、分布外行为和相同预算的多种子主动学习对照。本次没有加入 SVR、MLP、GNN、XGBoost、LightGBM，也没有把演示曲线当作上述模型的比较结果。

## 算法依据

- [GPML，第 2 章，算法 2.1](https://gaussianprocess.org/gpml/chapters/RW2.pdf)：GP 后验与 Cholesky 实现。
- [scikit-learn：集成方法](https://scikit-learn.org/stable/modules/ensemble.html)：RF、Extra Trees、梯度提升定义；本项目未引入 Python sklearn。
- [kNeighborsRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.KNeighborsRegressor.html)、[Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)：算法与正则目标定义。
- [Wager 等，2014](https://www.jmlr.org/papers/volume15/wager14a/wager14a.pdf)：森林预测不确定性与树间方差的区别。
